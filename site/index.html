❯ # an AI that follows you into ssh and vim

blockterm runs your real shell inside a terminal it controls. That is what lets it show every command as a block, and lets an AI agent read and type into whatever is on screen — a server you reached over ssh, a file open in vim — once you approve each step. It is in early development: the terminal works today, and blocks and the agent are being built.

What it is being built to do

Commands as blocks
Each command and its output is one block with ✔ or ✘, the exit code and how long it took. Copy it, rerun it, or ask why it failed.
An agent that sees the whole screen
blockterm owns the terminal, so the agent can read a remote shell or a vim buffer and type into it. Every keystroke it wants to send waits for your approval.
Your model, your key
Pick @ai-sdk/anthropic, @ai-sdk/openai or @ai-sdk/openai-compatible (Ollama, LM Studio) and type the model name. Keys stay in your environment variables.

Install

  1. Install Node.js 24 or newer

    Windows
    winget install OpenJS.NodeJS.LTS
    macOS
    brew install fnm eval "$(fnm env)" && fnm install 24 && fnm use 24
    Linux
    curl -fsSL https://fnm.vercel.app/install | bash export PATH="$HOME/.local/share/fnm:$PATH" eval "$(fnm env)" && fnm install 24 && fnm use 24

  2. Build blockterm from source

    git clone https://github.com/PydevAzmi/Blockterm.git cd Blockterm npm install && npm run build && npm link

    On Linux, building needs python3, make and g++. npm i -g blockterm arrives with the first release.

  3. Run it

    blockterm
